01 / THESIS RESEARCH · ONGOING

PhishEvade

Obfuscation-aware phishing URL detection

Our research examines URL features that may reveal phishing attempts hidden through encoding, nested structures, and other forms of obfuscation. The repository contains datasets, feature extraction pipelines, and Jupyter notebooks for traditional machine learning models.

PythonFeature engineeringMachine learning
My involvement & learning

I am a co-author in a three-person thesis team. This work connects my interest in defensive security with research on how URL structure can support detection. It strengthens my understanding of feature design, model comparison, and the need to evaluate claims carefully.

The repository describes Logistic Regression, Naïve Bayes, Random Forest, AdaBoost, and XGBoost. This portfolio presents the research focus without claiming final accuracy or production readiness.

Explore research repository
02 / NETWORK SECURITY · TEAM PROJECT

Visual Network Traffic Analyzer

A Python tool for capturing packets and displaying device activity, protocol distribution, top talkers, and throughput. Captures can be exported as PCAP files for further inspection in Wireshark.

PythonScapyPyQt5Matplotlib
My involvement & learning

I helped build this analyzer as part of a three-person team. The project gave me practice turning packet data into readable charts and tables and connecting live monitoring with deeper packet analysis.

The README includes a comparison procedure using Wireshark. Learning to compare outputs reinforced the importance of checking a tool’s results.
